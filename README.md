# react_typescript_materialui_usm_boilerplate

A React + TypeScript starter (Create React App) with Material-UI and usm-redux state — Redux without the reducer ceremony, plus a working counter.

## What's included

- **React** via Create React App, in TypeScript
- **usm-redux** on top of `react-redux` — a `StatesController` class instead of actions/reducers
- **Material-UI** with a theme file
- **A working counter component** showing how to read and mutate state

## Project layout

```
src/index.tsx                   redux provider + MUI theme
src/App.tsx                     the app shell
src/Components/Counter.tsx      reads and mutates the state
src/Others/StatesController.ts  the usm-redux state
src/Others/Theme.ts             MUI theme
```

## Getting started

```bash
git clone https://github.com/p32929/react_typescript_materialui_usm_boilerplate.git
cd react_typescript_materialui_usm_boilerplate
npm install
npm start          # http://localhost:3000

npm run build
npm test
```
